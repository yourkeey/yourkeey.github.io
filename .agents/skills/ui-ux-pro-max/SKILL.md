# UI UX Pro Max: Engineering & Conversion Strategy

This skill provides full design and UX rules for commercial developer portfolios, SaaS interfaces, and interactive dashboards.

## 1. Information Architecture & Conversion Flow
A commercial engineer's portfolio must guide the client through 5 cognitive phases:
1. **Instant Clarity (Hero):** Who is this, what specific high-value problems do they solve, and what is the immediate proof?
2. **Interactive Proof (Live Digital Twin):** Don't just tell — let them touch the working system (Bot + CRM + Live Store).
3. **Deep Commercial Cases:** Real-world metrics, architecture decisions, trade-offs, and load numbers.
4. **Transparent Engagement & Services:** Clear service categories, workflow stages, and timeline expectations.
5. **Frictionless CTA:** One-click contact to Telegram with pre-filled context, fast response guarantee.

## 2. Responsive Ergonomics & Touch Targets
- Mobile touch targets must be at least `44x44px`.
- Interactive simulator on mobile must have scroll protection (avoiding trapped scroll inside nested chat views).
- Responsive viewport toggles (Desktop / Tablet / Mobile) to demonstrate responsive mastery.

## 3. Data Density & Visual Feedback
- **Live State Indicators:** Pulsing live indicators (`live-dot`) for active engines.
- **Roll Counters:** Numbers should animate smoothly when state changes.
- **Instant Dispatch Validation:** Immediate visual feedback upon button clicks with clear success toasts and badges.

## 4. Accessibility & Polish Standards
- Keyboard navigability (`focus-visible` ring styles).
- High contrast compliant typography (WCAG 2.1 AA/AAA).
- Semantic HTML tags (`<header>`, `<main>`, `<section>`, `<article>`, `<dialog>`, `<footer>`).
