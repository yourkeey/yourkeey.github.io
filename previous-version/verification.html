Smoke-лічильник і pytest рахують різні набори перевірок; це не кількість унікальних користувацьких сценаріїв.

Що перевірено

Локальна копія поточної версії бота й CRM. Запуск через штатний інструмент tools/run_checks.py --all на синтетичних базах. Runner блокує робочий .env, доступ до робочої БД та зовнішню мережу.

Пропущені перевірки

Чотири перевірки інструмента випуску потребують Linux/POSIX. Ще одна пропущена через відсутність прав на створення symlink у Windows. Вони не зараховані до успішних.

Межі результату

Це локальний результат, а не підтверджений запуск GitHub Actions чи аудит production. Реальні замовлення, надсилання в Telegram та відповіді API Нової пошти цим запуском не перевірялися. Поточний бот залишається на етапі тестування.

Перший запуск у системній песочниці завершився таймаутом. Повторний запуск поза нею з власною ізоляцією runner завершився успішно. У звіті pytest є два попередження залежностей; помилок тестів немає.

Результат описує копію на дату перевірки. Після змін коду тести потрібно виконати знову. Публічний вихідний код зараз недоступний; цей звіт сам по собі не дає змоги незалежно відтворити перевірку.
